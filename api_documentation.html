API Documentation

เอกสารประกอบการเรียกใช้บริการ (Endpoints) ของระบบวิเคราะห์และสรุปแชตลูกค้าอัตโนมัติ (AI Triage System) สำหรับเชื่อมโยงร่วมกับหน้าจอระบบควบคุมส่วนกลาง (Back Office Dashboard) หรือระบบคิวรีข้อมูลอื่นๆ

Base URL
https://triage.dev-d.net
* หากทำ Cloudflare Tunnel โดเมนจะเปลี่ยนเป็นโดเมนคลาวด์ของคุณมิกะ
GET /health
ตรวจสถานะการทำงานหลังบ้าน เช็คว่าเชื่อมต่อ Ollama และตาราง Supabase สมบูรณ์ดีหรือไม่
รายละเอียดข้อมูล
พารามิเตอร์ ชนิด ความสำคัญ คำอธิบาย
ไม่มีพารามิเตอร์ส่งทาง Request

ตัวอย่างการเรียกใช้งาน (cURL):

cURL 
curl -X GET https://triage.dev-d.net/health
รูปแบบการตอบกลับ (Response)
HTTP 200 OK 
{
  "status": "healthy",
  "database": "connected",
  "ollama": "connected",
  "timestamp": "2026-07-10T10:15:30.123Z"
}
GET /api/chats/pending
ดึงรายการแชตของลูกค้าใน Supabase ทั้งหมดที่ค้างอยู่ (มีสถานะเป็น 'pending') รอวิเคราะห์ข้อมูลเชิงลึกด้วย AI
รายละเอียดข้อมูล
พารามิเตอร์ ชนิด ความสำคัญ คำอธิบาย
ไม่มีพารามิเตอร์ส่งทาง Request

ตัวอย่างการเรียกใช้งาน (Javascript):

fetch('https://triage.dev-d.net/api/chats/pending')

  .then(data => console.log(data));

POST /api/triage/run
สั่งการให้ระบบเริ่มรันคัดกรองวิเคราะห์แชตลูกค้าที่ค้างอยู่ในฐานข้อมูลทั้งหมด (ดึงแชต pending ส่งให้ Qwen 2.5 + คำนวณเวกเตอร์ BGE-M3 + หาประวัติคดีที่เหมือนกัน และอัปเดตกลับลง Supabase)
รายละเอียดข้อมูล
พารามิเตอร์ ชนิด ความสำคัญ คำอธิบาย
ไม่ต้องส่ง Body ส่งเฉพาะ Request เปล่า

ตัวอย่างการเรียกใช้งาน (cURL):

cURL 
curl -X POST https://triage.dev-d.net/api/triage/run
รูปแบบการตอบกลับ (Response)
HTTP 200 OK 
{
  "processedCount": 1,
  "successCount": 1,
  "failures": []
}
POST /api/triage/save
เขียนผลลัพธ์ข้อมูลคัดแยก AI บันทึกลงตารางแชตโดยตรงแบบ Manual (ใช้สำหรับทดสอบข้อมูลเข้าของตัวแปลรายคอลัมน์โดยตรง)
Request Body Parameters
พารามิเตอร์ ชนิด ความสำคัญ คำอธิบาย
id string Required ID ของแชตลูกค้าที่ต้องการบันทึก (เช่น "chat-001")
category_id string Required ID หมวดหมู่หลักในฐานข้อมูล (เช่น "deposit_withdrawal")
priority string Required ลำดับความสำคัญ: "low", "medium", "high", "urgent"
summary string Required สรุปเนื้อหาปัญหาของแชตใน 1 ประโยคภาษาไทย
department string Optional แผนกแนะนำ: "Finance", "Support", "Developer", "Marketing", "Admin", "VIP"
sentiment string Optional อารมณ์: "โกรธ", "ไม่พอใจ", "สับสน", "สงสัย", "ปกติ"
business_impact string Optional ความเสี่ยงธุรกิจ: "Revenue Risk", "Customer Risk", "None"

POST /api/chats/ingest
นำเข้าบทสนทนาแชตใหม่ล่าสุดของลูกค้าเข้าระบบ (เช่น เมื่อลูกค้าพึ่งทักแชตสดเข้ามา) โดย AI จะประเมินและคัดกรองในแบบเรียลไทม์ทันที
Request Body Parameters
พารามิเตอร์ ชนิด ความสำคัญ คำอธิบาย
id string Required ID ของห้องแชตลูกค้า (เช่น "chat-004")
customer_id string Required ID ของประวัติลูกค้า (เช่น "cust-001")
conversation string Required ข้อความบทสนทนาทั้งหมดที่เกิดในห้องแชตขณะนั้น

ตัวอย่างการเรียกใช้งาน (Javascript):

Fetch API 
fetch('https://triage.dev-d.net/api/chats/ingest', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    id: "chat-004",
    customer_id: "cust-001",
    conversation: "ลูกค้า: แอดมินคะ โอนเงินไปแล้วเครดิตไม่ขึ้นค่ะ"
  })
}).then(res => res.json()).then(console.log);
รูปแบบการตอบกลับ (Response)
HTTP 200 OK 
{
  "message": "Chat ingested successfully and queued for real-time AI Triage",
  "data": {
    "id": "chat-004",
    "customer_id": "cust-001",
    "conversation": "ลูกค้า: แอดมินคะ โอนเงินไปแล้วเครดิตไม่ขึ้นค่ะ",
    "status": "pending"
  }
}
POST /api/chats/feedback
ช่องทางส่งผลการประเมินและการแก้ไขของแอดมินกลับมาให้ AI เรียนรู้ (Human-in-the-Loop) พร้อมเก็บข้อมูลประวัติการตรวจทานและคะแนนไลก์ลงฐานข้อมูล
Request Body Parameters
พารามิเตอร์ ชนิด ความสำคัญ คำอธิบาย
chat_id string Required ID ของแชตลูกค้าที่ทำการตรวจทาน
is_correct boolean Required ผลการตรวจทาน: `true` (AI จัดกลุ่มถูก), `false` (จัดกลุ่มผิดและแก้ไข)
corrected_category_id string Optional ID หมวดหมู่ใหม่ที่ถูกต้อง (ส่งเมื่อ `is_correct` เป็น `false`)
liked_by string (uuid) Optional ID ของผู้ใช้หลังบ้านที่กดตรวจทาน (อ้างอิง `users.id`)
is_like boolean Optional ความพึงพอใจการทำงานของ AI: `true` (ถูกใจ), `false` (ไม่ถูกใจ)
comment string Optional คำติชมผลงานของ AI เพิ่มเติมโดยเจ้าหน้าที่
ตัวอย่าง Request JSON Body
JSON Body 
{
  "chat_id": "chat-004",
  "is_correct": false,
  "corrected_category_id": "promo_bonus",
  "liked_by": "ea764a96-2153-46b2-9359-96792894165a",
  "is_like": false,
  "comment": "จริงๆ แล้วลูกค้าถามเรื่องโปรโมชั่นสะสมเทิร์นโอเวอร์ ไม่ใช่ปัญหาเรื่องโอนเงิน"
}
