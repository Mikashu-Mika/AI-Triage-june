# ขั้นตอนเปิดใช้ Sift AI ให้บริษัทลูกค้า

เอกสารนี้มี 2 ส่วน
- **ส่วน A สำหรับทีม Sift AI:** ขั้นตอนเปิดบริษัทใหม่ และวิธีถอยกลับถ้ามีปัญหา
- **ส่วน B สำหรับลูกค้า:** ส่งให้ลูกค้าอ่านได้ทั้งส่วน ไม่มีข้อมูลภายใน

> อย่าใส่ Client Secret, รหัสผ่าน หรือคีย์จริงลงในเอกสารนี้ เพราะ repo นี้เป็น public

# ส่วน A: สำหรับทีม Sift AI

## A1. ก่อนเริ่ม

| ต้องมี | ได้จากไหน |
|---|---|
| ชื่อบริษัท และชื่อย่อภาษาอังกฤษ (ใช้เป็น domain เช่น `oneboxx`) | ลูกค้า |
| แพ็กเกจที่ตกลงกัน | ฝ่ายขาย |
| ชื่อและอีเมลของแอดมินฝั่งลูกค้า | ลูกค้า |
| กลุ่ม Telegram สำหรับถามบอตเรื่องแชตของบริษัท (ถ้าแพ็กเกจรองรับ) | ลูกค้าสร้างกลุ่ม แล้วเพิ่มบอต Sift AI เข้ากลุ่ม |
| บัญชี **System Admin** ใน Back Office | ทีมเรา มีแค่ role นี้ที่เปิดบริษัทได้ |

แพ็กเกจที่มีตอนนี้

| แพ็กเกจ | โควตาแชตต่อเดือน | กลุ่ม Telegram |
|---|---|---|
| Starter | 20,000 | ไม่รวม |
| Pro | 50,000 | 1 กลุ่ม |
| Enterprise | 120,000 | สูงสุด 3 กลุ่ม |
| Custom | ไม่จำกัด | ไม่จำกัด |

## A2. เปิดบริษัทใน Back Office

ไปที่เมนู **จัดการบริษัท** แล้วกด **สร้างและส่งมอบบริษัทใหม่** ระบบจะพาทำทีละขั้น

1. **ข้อมูลบริษัท:** ใส่ชื่อบริษัทและ domain (ภาษาอังกฤษพิมพ์เล็ก ไม่เว้นวรรค)
   ระบบจะสร้าง Client ID / Client Secret และหมวดหมู่พื้นฐาน 3 หมวดให้อัตโนมัติ
2. **เลือกแพ็กเกจ:** เลือกตามที่ตกลงกับลูกค้า
3. **สร้างแอดมิน:** ใส่ชื่อและอีเมลแอดมินฝั่งลูกค้า เลือก role `admin` หรือ `staff`
   ระบบสุ่มรหัสผ่านให้ ลูกค้าควรเปลี่ยนรหัสหลัง login ครั้งแรก
4. **ผูก Telegram:** เลือกกลุ่มที่บอตเข้าไปแล้ว หรือกรอก Chat ID (เช่น `-1001234567890`)
   ข้ามขั้นนี้ไปก่อนได้ แล้วค่อยผูกภายหลังที่เมนู **จัดการกลุ่ม Telegram**

จบแล้วจะได้ **ใบส่งมอบระบบ** ที่มี Client ID, Client Secret และบัญชีแอดมิน

- ส่ง Client Secret ให้ลูกค้าทางช่องทางที่ปลอดภัย และอย่าส่งในกลุ่มแชตที่มีคนนอก
  (System Admin เปิดดู Secret ได้อีกครั้งในตารางเมนู **จัดการบริษัท**)
- ดาวน์โหลด **เอกสาร API** ได้จากปุ่มบนเมนู **จัดการบริษัท** แล้วส่งให้ทีมเทคนิคของลูกค้า
  มีให้เลือก HTML, Markdown หรือ .txt ส่วนตัวอย่าง curl และ Postman อยู่ที่ [`docs/ingest/`](ingest/)

## A3. เชื่อมกลุ่ม Telegram

1. ลูกค้าเพิ่มบอต Sift AI เข้ากลุ่ม บอตจะทักในกลุ่มว่าให้ไปผูกกลุ่มใน Back Office
2. กลุ่มจะขึ้นเป็น **ไม่ได้ผูกในระบบ** ที่เมนู **จัดการกลุ่ม Telegram**
3. ผูกกลุ่มกับบริษัท แล้วตรวจว่าสถานะเป็น **เปิดใช้งาน**

หลังผูกแล้ว สมาชิกในกลุ่มถามบอตเรื่องแชตของ**บริษัทตัวเองเท่านั้น**ได้ เช่น "วันนี้มีปัญหาเรื่องอะไรบ้าง"
ถ้ากลุ่มยังไม่ได้ผูกหรือถูกปิดไว้ บอตจะตอบว่ากลุ่มยังไม่ได้เชื่อมกับบริษัท และไม่ตอบข้อมูลใดๆ

หลังผูกแล้ว กลุ่มจะได้สรุปประจำวัน (11:00) และสรุปรายสัปดาห์ (จันทร์ 11:15) ของบริษัทนั้นเองโดยอัตโนมัติ
ถ้าปิดใช้งานกลุ่ม สรุปจะหยุดส่ง

## A4. ตรวจก่อนส่งมอบ

- [ ] แอดมินฝั่งลูกค้า login Back Office ได้ และเห็นเฉพาะข้อมูลบริษัทตัวเอง
- [ ] ลูกค้าส่งแชตทดสอบ 1 ห้องผ่าน `POST /api/chats/ingest` แล้วได้ `200`
- [ ] ภายในประมาณ 1 นาที แชตขึ้นในเมนู **รายการแชตลูกค้า** พร้อมหมวดปัญหา ความเร่งด่วน และสรุป
- [ ] ส่ง `id` เดิมซ้ำแล้วยังมีแชตเดียว (ดูหัวข้อ "ส่งแชตเดิมซ้ำ" ในเอกสาร API)
- [ ] เมนู **การใช้งานและโควต้า** แสดงแพ็กเกจและจำนวนแชตถูกต้อง
- [ ] (ถ้ามี Telegram) กลุ่มผูกกับบริษัทถูกต้อง เปิดใช้งานอยู่ และลองถามบอตในกลุ่มแล้วได้ข้อมูลของบริษัทนี้
- [ ] แจ้งลูกค้าให้ลบแชตทดสอบ หรือแจ้งทีมเราให้ลบให้

## A5. วิธีถอยกลับเมื่อมีปัญหา

> **ร่าง:** ทีมยังไม่ได้ตกลงขั้นตอนนี้ร่วมกัน ควรรีวิวก่อนใช้จริง

เริ่มจากวิธีที่เบาที่สุดก่อน แล้วค่อยใช้วิธีที่หนักขึ้น

| สถานการณ์ | ทำอะไร | ทำที่ไหน | กลับคืนได้ไหม |
|---|---|---|---|
| บอตใน Telegram ตอบผิด หรือกลุ่มผูกผิดบริษัท | ปิดใช้งานกลุ่ม หรือถอดกลุ่มออกจากบริษัท | Back Office เมนู **จัดการกลุ่ม Telegram** | ได้ เปิดหรือผูกใหม่ได้ทันที |
| ต้องหยุดรับแชตใหม่ชั่วคราว | ตั้ง `package_status` เป็น `suspended` ระบบจะตอบ `429` และไม่บันทึกแชต | API ของบอต `PUT /api/companies/:id/package` ส่ง header `X-Admin-Key` | ได้ ตั้งกลับเป็น `active` |
| ยกเลิกสัญญา | ตั้ง `package_status` เป็น `cancelled` | API เดียวกัน | ได้ แต่ควรแจ้งลูกค้าก่อน |
| Client Secret หลุด | สร้าง secret ใหม่ แล้วส่งให้ลูกค้า ของเก่าจะใช้ไม่ได้ทันที | **ยังไม่มีปุ่ม** ต้องแก้ใน Supabase ตาราง `companies` | ไม่ได้ (ลูกค้าต้องเปลี่ยน secret ในระบบของตัวเอง) |
| ต้องปิดบัญชีผู้ใช้ของลูกค้า | ลบผู้ใช้ (Back Office เมนู **จัดการผู้ใช้งาน**) หรือตั้ง `is_active = false` (Supabase ตาราง `users`) | Back Office หรือ Supabase | ลบแล้วกลับไม่ได้ ส่วนปิดใช้งานเปิดคืนได้ |
| ลูกค้าขอลบข้อมูลทั้งหมด | ลบตามลำดับ: `chat_issues` → `chats` → `customers` → `categories` → `telegram_groups` ของบริษัท → `users` → `companies` | **ยังไม่มีปุ่ม** ต้องทำใน Supabase | **ไม่ได้** ควร export ข้อมูลเก็บไว้ก่อน และให้ทีมยืนยันเป็นลายลักษณ์อักษร |

สิ่งที่ยังขาดในระบบ (ควรทำก่อนเปิดใช้หลายบริษัท)
- ปุ่มหมุน Client Secret ใน Back Office
- ปุ่มระงับ / เปิดบริษัทใน Back Office (ตอนนี้ต้องเรียก API ด้วย admin key)
- ปุ่มลบข้อมูลบริษัทแบบครบชุด พร้อมบันทึก audit log
- ส่งสรุปประจำวันเข้ากลุ่ม Telegram ของแต่ละบริษัท (ตอนนี้ส่งแค่กลุ่มผู้บริหาร)

# ส่วน B: สำหรับลูกค้า

## B1. Sift AI ทำอะไรให้

ระบบของคุณส่งบทสนทนาแชตลูกค้ามาที่ Sift AI แล้ว AI จะวิเคราะห์แต่ละแชตให้
- **หมวดปัญหา** และหมวดย่อย
- **ความเร่งด่วน** (`low` / `medium` / `high` / `urgent`) และแผนกที่ควรรับเรื่อง
- **สรุป** อารมณ์ลูกค้า และคำตอบแนะนำ
- **รายการปัญหาย่อย** ถ้าแชตเดียวมีหลายเรื่อง

ดูผลได้ที่ Back Office และถามบอตเรื่องแชตของบริษัทคุณในกลุ่ม Telegram ได้ (ถ้าแพ็กเกจรองรับ)

## B2. สิ่งที่คุณจะได้รับจากทีม Sift AI

- **Client ID และ Client Secret:** ใช้ส่งแชตเข้าระบบ เก็บ Secret ไว้ฝั่ง server เท่านั้น ห้ามใส่ในแอปหรือหน้าเว็บ
- **บัญชีแอดมิน Back Office:** เปลี่ยนรหัสผ่านหลัง login ครั้งแรก
- **เอกสาร API** พร้อมตัวอย่าง curl และ Postman collection

## B3. ขั้นตอนเริ่มใช้

1. Login Back Office แล้วเปลี่ยนรหัสผ่าน
2. (ถ้ามี Telegram) สร้างกลุ่ม แล้วเพิ่มบอต Sift AI เข้ากลุ่ม แจ้งชื่อกลุ่มให้ทีม Sift AI ผูกให้
3. ทีมเทคนิคต่อระบบตามเอกสาร API ส่งแชตทดสอบ 1 ห้อง แล้วดูว่าขึ้นใน Back Office
4. ตรวจหมวดปัญหาที่ได้ ถ้าอยากเพิ่มหรือแก้หมวด แก้ได้ที่เมนู **จัดการหมวดหมู่** (บัญชีแอดมิน) หรือแจ้งทีม Sift AI
5. เริ่มส่งแชตจริง

## B4. สิ่งที่ควรรู้

**เวลา**
- AI ใช้เวลาประมาณ **30 วินาทีต่อแชต** ถ้ามีแชตเข้าพร้อมกันมาก จะเข้าคิวและนานขึ้น
- ส่งแชตเมื่อห้องแชตปิด หรือเมื่อลูกค้าหยุดพิมพ์สักพัก ไม่ต้องส่งทุกข้อความ
- ถามบอตใน Telegram ได้ตลอด แต่บอตอาจตอบช้าลงตอนที่มีแชตรอวิเคราะห์เยอะ

**ข้อมูลที่เก็บ**
- บทสนทนาที่ส่งมา, รหัสแชต (`id`), รหัสลูกค้า (`customer_id`) และผลวิเคราะห์ของ AI
- ระบบไม่ต้องใช้ชื่อจริง เบอร์โทร หรืออีเมลของลูกค้า ใช้รหัสภายในของคุณเป็น `customer_id` ได้เลย
- ถ้าในบทสนทนามีข้อมูลส่วนตัว ข้อมูลนั้นจะถูกเก็บไปด้วย ควรตัดออกก่อนส่งถ้าทำได้
- บทสนทนาถูกส่งไปให้ผู้ให้บริการ AI ที่ Sift AI ใช้ เพื่อวิเคราะห์
- ข้อมูลของแต่ละบริษัทแยกจากกัน ผู้ใช้เห็นเฉพาะข้อมูลบริษัทตัวเอง
- ข้อมูลเก็บไว้จนกว่าจะขอลบ ติดต่อทีม Sift AI ได้

**โควตา**
- นับตามจำนวนห้องแชต (`id`) ที่สร้างในรอบบิล ส่ง `id` เดิมซ้ำไม่นับเพิ่ม
- เมื่อโควตาเต็ม ระบบจะตอบ `429` และ**ไม่บันทึก**แชตนั้น ดูยอดใช้ได้ที่เมนู **การใช้งานและโควต้า**

## B5. ถ้ามีปัญหา

| อาการ | ทำอย่างไร |
|---|---|
| ได้ `401` | ตรวจ Client ID / Secret ถ้า Secret อาจหลุด แจ้งทีม Sift AI เพื่อออกอันใหม่ |
| ได้ `429` | โควตาเต็มหรือแพ็กเกจถูกระงับ หยุดส่งแล้วแจ้งทีม Sift AI |
| ได้ `500` / `502` / `503` หรือ timeout | ส่งซ้ำด้วย `id` เดิม เว้นระยะ 5, 30, 120 วินาที |
| แชตขึ้นแต่ไม่มีผลวิเคราะห์เกิน 10 นาที | แจ้งทีม Sift AI พร้อมรหัสแชต |
| ผลวิเคราะห์ผิด | แก้ในหน้าแชตของ Back Office ผลที่คนแก้แล้วจะไม่ถูก AI วิเคราะห์ทับ ถ้าบทสนทนาไม่เปลี่ยน |
| ไม่อยากใช้บอตใน Telegram แล้ว | เอาบอตออกจากกลุ่ม หรือแจ้งทีม Sift AI ให้ปิดกลุ่ม |
| ต้องการหยุดใช้หรือลบข้อมูล | แจ้งทีม Sift AI เป็นลายลักษณ์อักษร |
