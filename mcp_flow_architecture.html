AI Triage: MCP System Architecture & Flow

สวัสดีครับคุณอ้อ! โครงการ AI Triage นี้เป็นระบบที่จะช่วยนำแชตของลูกค้ามาวิเคราะห์ จัดหมวดหมู่ และบันทึกผลสถิติลงฐานข้อมูลโดยอัตโนมัติ เพื่อนำไปแสดงผลบน Dashboard เชิงลึกครับ

เอกสารฉบับนี้อธิบายโครงสร้าง สถาปัตยกรรม และการไหลของข้อมูล (System Flow) ของระบบเพื่อเป็นไกด์ไลน์เริ่มต้นให้คุณอ้อนำไปศึกษาและทำตามได้ทันที

1. แผนผังการทำงานของระบบ (System Flow Diagram)

นี่คือโฟลวการทำงานตั้งแต่เริ่มรับข้อความแชตของลูกค้า ไปจนถึงการประมวลผลของ AI และอัปเดตสถิติขึ้นสู่หน้าบ้าน (Dashboard) ผ่านโปรโตคอล MCP:

                    sequenceDiagram
                        autonumber
                        participant DB as Database (JSON / SQLite)
                        participant MCPServer as MCP Server (Node.js)
                        participant AIClient as AI Client (Gemini/Claude)
                        participant Dashboard as Dashboard UI (HTML/CSS/JS)

                        Note over AIClient, MCPServer: 1. ขั้นตอนการวิเคราะห์และคัดแยก (Triage Flow)
                        AIClient->>MCPServer: ขอข้อมูลแชตที่ยังไม่ได้คัดแยก (Call tool: get_unclassified_chats)
                        MCPServer->>DB: Query ข้อมูลแชตดิบ (Raw Chats)
                        DB-->>MCPServer: ส่งข้อมูลแชตกลับมา
                        MCPServer-->>AIClient: ส่งรายการแชตกลับไปให้ AI

                        Note over AIClient: AI วิเคราะห์ข้อความแชต:
- หมวดหมู่ (เช่น ฝาก-ถอน, เข้าเว็บไม่ได้)
- ความเร่งด่วน (High/Medium/Low)
- บทสรุปสั้นๆ

                        AIClient->>MCPServer: ส่งผลลัพธ์ไปบันทึก (Call tool: save_triage_result)
                        MCPServer->>DB: บันทึกข้อมูลหมวดหมู่และระดับความสำคัญ
                        DB-->>MCPServer: ยืนยันการบันทึกสำเร็จ
                        MCPServer-->>AIClient: ส่งผลลัพธ์ Success

                        Note over Dashboard, DB: 2. ขั้นตอนการแสดงผล (Dashboard Flow)
                        Dashboard->>MCPServer: ขอข้อมูลสถิติ (REST API หรือ Resource)
                        MCPServer->>DB: ดึงผลสถิติสรุป (Count by Category, Priority)
                        DB-->>MCPServer: ส่งผลสถิติกลับมา
                        MCPServer-->>Dashboard: ส่งข้อมูล JSON ไปแสดงผลบนแผนภูมิ/ตาราง

2. ส่วนประกอบหลักของระบบ (Core Components)

ระบบของเราจะแบ่งการเชื่อมต่อการทำงานออกเป็น 3 ส่วนสำคัญหลักๆ:

MCP Server

  • เขียนด้วย Node.js เป็นทางผ่านการคุยของ AI กับฐานข้อมูล
  • เตรียมเครื่องมือ (Tools) เช่น get_unclassified_chats
  • เตรียมช่องทางส่งบันทึก save_triage_result

Database (JSON / SQLite)

  • ใช้เก็บข้อมูลแชตดิบของลูกค้าที่เข้ามา
  • เก็บผลการวิเคราะห์ของ AI (Category, Priority, Summary)
  • ช่วงแรกแนะนำให้เก็บในไฟล์ db.json เพื่อการพัฒนาที่ง่ายและไม่มีบั๊กบน Windows

Dashboard UI

  • เว็บอินเทอร์เฟสสวยงาม ดึงข้อมูลสถิติไปจัดทำกราฟ
  • ช่วยผู้ใช้คัดกรองดูเคสด่วนที่สุด (High Priority) ได้ก่อน
  • พัฒนาด้วย HTML, Vanilla CSS และ JavaScript รวดเร็วลื่นไหล

3. โครงสร้างข้อมูลที่ต้องใช้ (Database Schema Example)

ตารางหลักที่เราจะใช้ในการจัดเก็บข้อมูลแชตลูกค้าและประมวลผล (ตาราง chats):

ชื่อฟิลด์ (Column Name) ประเภท (Type) คำอธิบาย (Description)
id TEXT (PK) รหัสไอดีของแต่ละแชตเซสชัน (เพื่อใช้อ้างอิง)
customer_name TEXT ชื่อหรือข้อมูลติดต่อเบื้องต้นของลูกค้า
conversation TEXT ประโยคพูดคุยทั้งหมดระหว่างลูกค้าและระบบช่วยเหลือ
status TEXT สถานะคัดกรอง (pending = รอประเมิน, completed = ประเมินแล้ว)
category TEXT หมวดหมู่ที่วิเคราะห์ได้ (เช่น deposit_withdrawal, login_issue)
priority TEXT ความเร่งด่วนของเคส (low, medium, high, urgent)
summary TEXT สรุปเนื้อความของแชตสั้นๆ เพื่อให้เจ้าหน้าที่เปิดอ่านได้ทันที
created_at TIMESTAMP เวลาที่ลูกค้าสร้างแชตเข้ามา

4. แผนการดำเนินการขั้นตอนต่อไป (Next Steps)

เรามาเริ่มดำเนินการทีละขั้นตอนไปด้วยกันได้เลยครับ:

ขั้นตอนที่ 1: เตรียมสภาพแวดล้อมโปรเจกต์ (Project Setup)

สร้างโครงสร้างโฟลเดอร์สำหรับเขียนโค้ด ทำการ npm init -y และทำการติดตั้งไลบรารีเบื้องต้นเพื่อเตรียมพร้อมสำหรับ MCP Server

ขั้นตอนที่ 2: สร้างระบบ Database แบบไฟล์ JSON

เราจะสร้างไฟล์ db.json พร้อมข้อมูลตัวอย่างของลูกค้า (เช่น ลูกค้าโอนเงินไม่เข้า, เข้าเว็บไม่ได้) เพื่อให้ AI ได้ฝึกคัดแยก

ขั้นตอนที่ 3: พัฒนา MCP Server และระบบวิเคราะห์ของ AI

เขียนโค้ดเปิดใช้เครื่องมืออ่านและเขียนฐานข้อมูล และรันสคริปต์ให้ AI อ่านแชตและวิเคราะห์อัปเดตลงไฟล์โดยอัตโนมัติ

ขั้นตอนที่ 4: ทำหน้าจอ Dashboard สุดพรีเมียม

สร้างหน้าจอ Dashboard ดึงสถิติกราฟวิเคราะห์และรายการแชตจากฐานข้อมูลให้แสดงผลแบบโต้ตอบได้อย่างสวยงาม

คำแนะนำสำคัญสำหรับคุณอ้อ

คุณอ้อไม่จำเป็นต้องมีพื้นฐานการเขียนโปรแกรมมาก่อนครับ ผมจะคอยเขียนสคริปต์ให้ และแนะนำทีละจุดอย่างใจเย็น สามารถทดลองเปิดไฟล์ HTML หน้านี้กับบราวเซอร์ดูการเปลี่ยนหน้าได้เลยครับ!
